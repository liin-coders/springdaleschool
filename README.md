# Spring Dales English School, Kathua — Redesigned Website

Complete, SEO-optimized 6-page static website redesign for **Spring Dales English School, Changran, Kathua (J&K)** — built with clean HTML5, CSS3, and Vanilla JavaScript.

## Included Pages & Files
- `index.html` — Home (Hero, Live Stats, Value Bento Grid, Academic Pathways, ATL Spotlight, Hall of Fame, Alumni Testimonials, Admissions CTA)
- `about.html` — About Us (35-Year Heritage, Vision & Mission, Leadership Profiles, Education Today Rankings Timeline)
- `academics.html` — Academics (Foundational to Secondary Stages, Interactive Science/Commerce/Arts Stream Tabs, Pedagogy)
- `facilities.html` — Campus & Facilities (NITI Aayog Atal Tinkering Lab, Labs, Smart Classrooms, Library, Transport, Sports & Student Clubs)
- `admissions.html` — Admissions 2026–27 (4-Step Process, Document Checklist, Interactive Enquiry Form with WhatsApp handoff, FAQ Accordion)
- `contact.html` — Contact Us (Direct Campus Info, Contact Form, Embedded Google Map for Changran, Kathua)
- `css/style.css` — Full responsive design system (Royal Navy `#0B1F3A`, Heritage Gold `#C89B3C`, Warm Ivory `#FAF9F6`)
- `js/main.js` — Interactive mobile drawer, scroll animations, stat counters, tabs, accordions, and form validation

## Quick Deployment
1. Unzip `spring-dales-kathua-redesign.zip`.
2. Open `index.html` locally in any browser to preview immediately.
3. Upload the folder contents to **Netlify**, **GitHub Pages**, **Vercel**, or **cPanel `public_html`**.
4. Replace the two placeholder Unsplash stock photos (`index.html` & `facilities.html`) with actual school campus / ATL photos before going live.
